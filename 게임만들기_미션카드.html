팀 미션 · 40~50분

코딩 몰라도 게임 만든다

코드는 AI가 쓰고, 너희는 말로 시킨다. 레벨을 하나씩 깨면서 우리 팀만의 게임을 완성하고, 마지막에 발표해서 우승팀을 뽑는다. 주문 상자의 글은 복사해서 그대로 붙여 넣어도 되고, 마음대로 바꿔도 된다.

시작 전에

  • 팀당 노트북 1대, 부모님 계정으로 AI 채팅(Claude, ChatGPT, Gemini 중 하나)을 열어 둔다.
  • AI가 만든 게임은 채팅창 옆 미리보기 화면에서 바로 실행된다.
  • 미리보기가 안 뜨면: 코드를 복사해 메모장에 붙여 넣고 game.html로 저장한 뒤 더블클릭.
  • 키보드 담당과 아이디어 담당을 레벨마다 바꾼다.

잘 먹히는 주문 공식

무엇을+어떻게 움직이고+조건+분위기
대충: 게임 만들어줘
제대로: 위에서 떨어지는 운석을 좌우 화살표로 피하는 게임. 오래 버틸수록 점수가 오르고, 부딪히면 게임오버. 우주 배경에 네온 느낌으로.
LEVEL1

일단 돌아가게

5분 · 기본 피하기 게임 띄우기

주문

HTML 파일 하나로 실행되는 피하기 게임을 만들어줘. - 화면 아래의 캐릭터를 키보드 왼쪽/오른쪽 화살표로 움직인다. - 위에서 장애물이 랜덤으로 떨어진다. - 피한 시간만큼 점수가 오르고, 부딪히면 게임오버 화면에 점수가 나온다. - 스페이스바를 누르면 다시 시작한다.

성공 기준: 캐릭터가 움직이고, 부딪히면 게임오버가 뜬다.

LEVEL2

우리 팀 색깔 입히기

10분 · 테마를 정해서 바꾸기

팀에서 테마를 하나 고른다. 아래는 예시일 뿐이고, 새로 생각해 내면 보너스.

우주

배경을 별이 흐르는 우주로 바꾸고, 캐릭터는 🚀, 떨어지는 건 ☄️ 운석으로 바꿔줘.

급식실

배경을 학교 급식실로 바꾸고, 캐릭터는 식판, 떨어지는 건 🥦 브로콜리랑 🐟 생선으로 바꿔줘. 가끔 🍗 치킨이 떨어지면 먹어서 점수 +10.

시험 기간

캐릭터는 학생, 떨어지는 건 📝 시험지와 📚 문제집으로 바꿔줘. 화면 위에 '기말고사까지 D-?' 글자가 나오게 해줘.

LEVEL3

규칙 추가로 더 재밌게

10분 · 최소 2개 추가

난이도

10초가 지날 때마다 장애물이 조금씩 빨라지고 더 많이 떨어지게 해줘.

생명

하트 3개로 시작하고, 부딪힐 때마다 하트가 하나씩 줄어. 다 없어지면 게임오버. 부딪힌 직후 1초 동안은 깜빡이면서 무적.

아이템

가끔 ⭐ 별이 떨어지는데, 먹으면 3초 동안 무적이 되고 캐릭터가 반짝여.

최고 기록

최고 점수를 저장해서 화면 오른쪽 위에 'BEST: 점수'로 보여줘. 새로고침해도 남아 있게.

LEVEL4

버그 잡기

수시로 · 이상하면 바로 AI에게 신고

"안 돼"라고만 하면 AI도 모른다. 세 가지를 꼭 말해 준다: 무엇을 했더니 → 어떻게 됐고 → 원래는 어떻게 되길 원하는지.

버그 신고 예시

게임오버가 된 다음에 스페이스바를 눌렀는데 아무 일도 안 일어나. 스페이스바를 누르면 점수가 0으로 돌아가고 처음부터 다시 시작했으면 좋겠어. 고쳐줘.

하나를 고쳤더니 다른 게 망가지면: "방금 바꾼 거 되돌리고 다른 방법으로 해줘."

LEVEL5

우리만의 한 방

10분 · 다른 팀이 안 할 것 하나

효과음

아이템 먹을 때, 부딪힐 때, 게임오버 때 짧은 효과음이 나게 해줘. 소리 파일 없이 코드로 만들어서.

보스

30초를 버티면 화면 위에 거대한 보스가 나타나서 좌우로 움직이며 장애물을 쏘게 해줘.

2인용

2인용 모드를 추가해줘. 1P는 A/D 키, 2P는 왼쪽/오른쪽 화살표. 먼저 하트를 다 잃는 사람이 패배.

LEVEL6

발표 준비

5분 · 팀당 2분 발표

  1. 게임 이름과 한 줄 소개
  2. 가장 자신 있는 기능 시연
  3. AI가 제일 말 안 들었던 순간과 어떻게 해결했는지
  4. 다른 팀 대표가 직접 한 판 플레이

피하기 게임 말고 다른 걸 하고 싶다면

반응속도 테스트화면이 초록색으로 바뀌는 순간 클릭. 0.001초 단위로 순위표.
친구 TMI 퀴즈우리끼리만 아는 문제 10개로 만드는 퀴즈 게임.
2인용 탁구한 키보드로 둘이 하는 퐁 게임. 공이 점점 빨라짐.
타자 연습 게임떨어지는 단어를 바닥에 닿기 전에 타자로 쳐서 없애기.
